Setup

This section renders live contributions, languages and repository stats as soon as a read-only GitHub token is configured. Add GITHUB_TOKEN to your .env (see .env.example) and reload.

  • Create a classic token with read:user and repo scopes (repo is only used for the private-repo count).
  • The token stays server-side — it is never sent to the browser.
  • Until then, the rest of the page works exactly as normal.
